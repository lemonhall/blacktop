# 截图来源

这批图不是手工截的，也不是摆拍的假数据：`tools/shots.mjs` **用真 Chrome 跑完一整局**，
在几个节点按快门——所以图和线上跑的是同一条链路。

```powershell
npx wrangler dev                    # 一个终端里起后端
node tools/shots.mjs                # 另一个终端里出图（覆盖本目录下的同名文件）
```

拍法：Playwright 驱动本机 Chrome（1440×900，`channel:"chrome"`），
进站 → 开一桌（夜色环路、满员 13 个机器人）→ 第二个浏览器看房间列表 →
房主发车 → 倒数 → 一直拧着油门跑到冲线 → 结算。

| 文件 | 拍到的瞬间 |
|---|---|
| `00-rooms.png` | 房间浏览器：卡片上有赛道、真人 n/2、机器人、举手数；右侧是排行榜与最近战绩 |
| `01-create-room.png` | 建房表单：赛道、难度、机器人、是否允许中途加入 |
| `02-lobby-staging.png` | 候场：名册（真人 + 13 个机器人）、选车台、举手与出发闸门 |
| `03-countdown.png` | 发车倒数：油门锁死的那 3.2 秒 |
| `04-race.png` | 对局中：伪 3D 路面、名次榜、播报条、双表盘仪表盘 |
| `05-brawl.png` | 混战：路上有人摔车，播报条在响 |
| `06-results.png` | 结算：名次、用时、撂倒、踢飞大运、赏金与完整成绩单 |
